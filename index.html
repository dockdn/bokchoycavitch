About automatic iCloud sync

Private automatic syncing and editing iCloud events need a secure server-side calendar connection, which this standalone HTML prototype does not have. Never enter your Apple ID password into this page. A public iCloud calendar subscription would expose calendar details to anyone with its link, so we are not using that as the default.
